# Paper V1 freeze amendment v2

Date: 2026-08-15
Supersedes: `paper-v1-experiment-freeze`
Replacement tag: `paper-v1-experiment-freeze-v2`

## Trigger

The first launcher invocation stopped during `RunRecorder.create`, before a run
manifest, LLM client, provider request, or confirmatory outcome existed. The
frozen plan hashed `wall_clock_limit_seconds` as JSON integer `1800`, while the
unchanged frozen runner's `argparse` contract materializes the same CLI value as
float `1800.0`. JSON canonicalization therefore produced different hashes for a
semantically identical 1,800-second limit.

The stopped attempt is retained outside Git with its launcher lifecycle and
stderr logs. It is not a planned attempt because no run manifest was created,
and it must not be included in analysis.

## Provenance roots

The stopped v1 lifecycle remains archived under external series ID
`paper-v1-confirmatory-20260815`. V2 must use a fresh sibling root with series
ID `paper-v1-confirmatory-20260815-v2`; its launcher receives the `runs/`
directory inside that root. The tagged freeze record binds both IDs, and the
launcher rejects any v2 invocation whose results-root name differs. V1 events
are never moved, rewritten, imported into v2 reconciliation, or analyzed.

## Result-blind change

Only the numeric serialization of the frozen wall-clock budget changes from
`1800` to `1800.0`. The effective time limit, token/call/execution/tool budgets,
datasets, models, prompts, arms, randomization seed, hypotheses, failure policy,
analysis, and bound execution commit remain unchanged.

The complete condition plan is regenerated before any provider request or
outcome is observed. New condition IDs and a new plan hash are expected because
the budget-policy hash is part of each condition. The original annotated tag
and stopped-launch audit trail remain immutable.
